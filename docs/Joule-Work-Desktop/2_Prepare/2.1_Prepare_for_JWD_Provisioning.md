# Prepare for Joule Work Desktop Provisioning

Before starting the setup of Joule Work Desktop, confirm the following requirements and understand the user roles that will be created during provisioning.

---

## Required Prerequisites

| Prerequisite | Details |
|---|---|
| **SAP AI Units** | Product number `8019164` — must be entitled in your SAP contract |
| **SAP Cloud Identity Services** | A **productive tenant** is required (not a test or trial tenant) |
| **S-User ID with Admin Privileges** | Administrator access to [me.sap.com](https://me.sap.com) |

## Optional Prerequisites

| Prerequisite | When Needed |
|---|---|
| **Microsoft Entra Administrator** | Required if you plan to enable Microsoft Entra SSO and Microsoft 365 email/calendar integration |

---

## Account Hierarchy Recommendation

JWD provisioning requires a **resource group** as the target container. Set up your SAP BTP account hierarchy before starting the provisioning wizard.

> **Tip:** If your account hierarchy is not yet configured, do this in the **Resources** tab of SAP for Me before starting provisioning.

### Recommended Structure

```
Organization (Global Account)
└── Resource Group (e.g., "JWD Resource Group")
    └── JWD Tenant (provisioned automatically)
```

---

## Supported Regions

During Early Adopter Care (EAC), JWD is available in:

| Region Label | SAP BTP Region |
|---|---|
| Germany / European Union | **EU10** (recommended) |
| USA / USA East | **US10** |

> **Note:** Germany (EU10) is the **preferred/recommended** region.

## User Roles Created During Provisioning

When provisioning completes, two authorization groups are automatically created in your **SAP Cloud Identity Services (IAS)** tenant:

| Group Name | Description |
|---|---|
| **`gateway - AdminJouleDesktop`** | Administrator role — grants access to the JWD Admin Portal to configure tenant settings |
| **`gateway - UseJouleDesktop`** | Standard user role — required for all end users to log in to JWD |

### What AdminJouleDesktop Can Do

Users assigned to this group can access the JWD Admin Web UI at:

```
https://joule-desktop-gateway.cfapps.<region>.hana.ondemand.com/<TENANT_ID>/admin/
```

From the admin portal, they can:
- Enable/disable automatic updates
- Set AI usage guidelines URL
- Enable Spaces
- Configure custom guardrails
- Set user quota (daily message limits)
- Configure Microsoft 365 email and calendar integration
- Set up a custom marketplace
- Add default MCP servers and access policies
- Export tenant data (JSON)

### What UseJouleDesktop Can Do

Users assigned to this group can:
- Log in to the JWD desktop client
- Use AI conversations, Spaces, and Skills
- Connect their Microsoft 365 email and calendar (if enabled by admin)
- Access extensions from the marketplace

> **Important:** Without assignment to `UseJouleDesktop`, users will receive an **Access Denied** error when trying to log in.
