## Tenant Lifecycle: Delete JWD

If you need to decommission the JWD tenant at the end of the EAC engagement, follow these steps.

> **Caution:** Deletion is **irreversible**. All tenant data, user sessions, and configuration are permanently removed.

### Pre-Deletion Checklist

- [ ] All JWD users have been notified
- [ ] Users have exported any important data: **Settings → Account → Personal Data → Export**
- [ ] You have confirmed this is the correct JWD tenant to delete
- [ ] You are **not deleting the Resource Group** — only the JWD solution entry

### Impact of Deletion

| Impact | Description |
|---|---|
| **Tenant data deleted** | All tenant configuration and stored data is permanently removed |
| **User sessions terminated** | All active JWD user sessions are immediately terminated |
| **User data lost** | Conversations, spaces, and skills saved in the client are lost |
| **Login disabled** | Users can no longer log in to JWD |
| **IAS cleanup** | The JWD application and associated user groups are deleted from IAS |

### Step-by-Step: Delete the JWD Tenant

1. Log in to [https://me.sap.com](https://me.sap.com)
2. Click **Portfolio & Products → My Product Packages → Artificial Intelligence → Joule**
3. Click the **Resources** tab
4. In the Resources hierarchy, locate your **JWD Solution entry** (not the Resource Group)
5. Click the **Actions** button (three-dot menu) next to the JWD tenant
6. Click **Delete**

A confirmation dialog appears. Check the box:
> ✅ *I confirm that I want to permanently delete this solution, including its data and tenants*

Click **Delete Solution and Tenants**.

### Post-Deletion Verification

After deletion:
- The JWD entry is removed from the Resources section in SAP4ME
- In **SAP Cloud Identity Services**, the JWD application is no longer visible under Applications
- The `gateway - AdminJouleDesktop` and `gateway - UseJouleDesktop` groups are removed from Groups

### Re-Provisioning

To set up JWD again after deletion, start the full provisioning process from [3_SetUp/3.1_Provision_JWD_in_SAP4ME.md](../3_SetUp/3.1_Provision_JWD_in_SAP4ME.md).
