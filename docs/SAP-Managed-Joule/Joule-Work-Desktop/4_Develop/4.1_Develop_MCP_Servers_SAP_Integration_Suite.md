# Develop and Connect MCP Servers with SAP Integration Suite

> **Optional** — Complete this step if you want to extend JWD with external data sources using Model Context Protocol (MCP) servers.

**MCP (Model Context Protocol)** servers are lightweight API adapters that give Joule Work Desktop access to external systems — such as SAP S/4HANA, ServiceNow, databases, or any REST API. Users can then query these systems conversationally from within JWD.

**SAP Integration Suite** is the recommended platform for building and hosting your own MCP servers on SAP BTP.

---

## Architecture Overview

```
JWD Desktop Client
        ↓
JWD Gateway (SAP BTP)
        ↓
MCP Server (hosted on SAP Integration Suite or any HTTPS endpoint)
        ↓
Backend System (SAP S/4HANA, external API, database, etc.)
```

The JWD Admin Portal manages which MCP servers are available to users and which endpoints users are allowed to access (via access policies).

---

## Prerequisites

- JWD provisioned and admin portal accessible
- Access to **SAP Integration Suite** on SAP BTP (for building a new MCP server)
- Target backend system credentials/API details

---

## Step 1 – Build an MCP Server with SAP Integration Suite

SAP Integration Suite provides a runtime environment for building and exposing MCP-compatible APIs.

For detailed guidance on building MCP servers, refer to:
- [SAP Help Portal: SAP Integration Suite](https://help.sap.com/docs/integration-suite)
- SAP Developer tutorials for MCP Server development

Your MCP server must expose endpoints that conform to the **Model Context Protocol** specification and be accessible over HTTPS.

---

## Step 2 – Register the MCP Server in the JWD Admin Portal

Once your MCP server is deployed and accessible:

1. Navigate to the **JWD Admin Portal**:
   ```
   https://joule-desktop-gateway.cfapps.<region>.hana.ondemand.com/<TENANT_ID>/admin/
   ```
2. Scroll to the **MCP Servers** section
3. Click **Add MCP Server**
4. Fill in the server details:

   | Field | Description |
   |---|---|
   | **Name** | A display name for the MCP server (visible to users) |
   | **URL** | The HTTPS endpoint of your MCP server |
   | **Description** | What data or capabilities this server provides |

5. Click **Save**

![Add MCP Server](./images/4.1.1.png)

---

## Step 3 – Configure MCP Access Policies

Access policies restrict which MCP server endpoints users can call. To add a policy:

1. In the **MCP Servers** section, click **Add MCP Access Policy**
2. Define the allowed endpoint patterns for your MCP server
3. Click **Save**

> **Tip:** Start with a permissive policy for testing, then tighten access for production use.

---

## Step 4 – Test in JWD Client

After saving the MCP server configuration:

1. Open the JWD desktop client
2. Navigate to **Extensions** — your MCP server should appear as an available connector
3. Start a conversation and invoke a capability from your MCP server, for example:
   ```
   What are my open purchase orders?
   ```

If the server is configured correctly, JWD will route the request to the MCP server and return the results.

---

## Troubleshooting

| Issue | Resolution |
|---|---|
| MCP server not visible in JWD | Verify the server URL is correct and accessible from the JWD gateway |
| "Unauthorized" error | Check that the MCP server authentication is configured correctly |
| No results returned | Confirm the MCP server is running and the access policy allows the requested endpoint |
